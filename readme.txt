AIKairali Portal provides a modular architecture for managing an AI directory, training tools, courses, models, prompts, glossary, and newsletter system.

== Description ==
An enterprise-grade WordPress plugin developed to power AI learning portals and directories.

== Installation ==
1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure the settings under the 'AIKairali' admin menu.
